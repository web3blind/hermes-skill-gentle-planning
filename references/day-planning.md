# Day Planning

Use when the user wants a realistic plan for today.

## Steps

1. Name the day constraint: time, energy, deadline, interruptions, recovery, or uncertainty.
2. Choose one main contour.
3. Define "enough for today" before listing tasks.
4. Add 2-4 blocks maximum.
5. Give every work block a success criterion and stop rule.
6. Add a lighter version if energy drops.
7. End with one thing not to chase.

## Template

```text
Main focus: <one direction>
Enough for today: <minimum useful outcome>

1. <Main block> — <duration or scope>
   Done when: <criterion>
   Stop: <rule>

2. <Support block> — <duration or scope>
   Done when: <criterion>
   Stop: <rule>

3. <Health / calm / maintenance>
   Done when: <small concrete action>

Optional: <timeboxed action only if energy remains>

Do not chase today: <boundary>
Lighter version: <fallback>
```

## Rules

- Do not make five priorities equal.
- Do not compensate for a bad yesterday by overloading today.
- If the user is tired, reduce scope before giving advice.
- If a task is large, plan a section, not the whole thing.
