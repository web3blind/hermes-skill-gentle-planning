# Week Planning

Use for weekly reset, Sunday/Monday planning, or when the user wants a stable direction.

## Steps

1. Review last week's facts if available.
2. Choose one main contour for the week.
3. Add supporting rhythm: admin, publishing, learning, health, relationship, or maintenance.
4. Identify likely pressure points.
5. Decide what not to do this week.
6. Define a good-week criterion that does not require perfection.

## Template

```text
Focus of the week: <one sentence>
Main contour: <project/theme>
Supporting rhythm: <2-3 recurring supports>
Known constraints: <limits>
Stop rule: <boundary>
Good week criterion: <directional success>
Not this week: <one or more exclusions>
```

## Review Questions

- Did the plan support direction or create pressure?
- What repeated?
- What caused overruns?
- What should stay stable?
- What should be reduced, expanded, or replaced?
