# Reviews

Use for day, week, or month reviews.

## Review Shape

```text
Facts:
Planned vs done:
What changed:
Diagnosis: plan problem / execution problem / constraint problem / pressure problem
Carryovers:
What to reduce:
Next small adjustment:
```

## Principles

- Use the user's own facts.
- Do not add motivational speeches.
- Do not change the system until the failure type is clear.
- Carry over less than the user wants if the list is already overloaded.
- Treat protected rest as a valid outcome when recovery was the real constraint.
