# Month Reset

Use when starting or closing a month. Keep it light: the month is an orientation snapshot, not a moral contract.

## Steps

1. Start from facts: what was actually done, repeated, avoided, delayed, or overrun.
2. Separate plan problems from execution problems and real constraints.
3. Choose one main contour for the next month.
4. Pick a sustainable rhythm for supporting work.
5. Define what must not become a second full-time project.
6. Add one stop rule for sleep, health, or deep-work spirals.
7. Define a weekly execution check.
